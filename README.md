## Featured Project

### BH Finder

**A Boarding-House Discovery Platform**

A platform designed to help students discover suitable boarding houses while providing landlords with tools to manage their property listings.

### Overview

BH Finder is a student-focused platform that connects tenants and landlords through a centralized property discovery experience.

### Key Features

- Property discovery and search
- Room listings and detailed property information
- Saved properties and favorites
- Tenant and landlord workflows
- Landlord verification system
- Administrative management
